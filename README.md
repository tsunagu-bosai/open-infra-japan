# Open Infra Japan

全国の自治体・公的機関が公開している施設オープンデータを収集し、共通形式で利用できるよう整理・正規化するプロジェクトです。

現在は主に **公衆トイレ** と **バリアフリー関連施設** のデータを整備しています。

防災、避難、地域サービス、地図アプリ、データ分析などで再利用しやすい形にすることを目的としています。

## このプロジェクトの基本方針

### 元データを尊重する

自治体・公的機関が公開した情報をもとに正規化します。

元データに存在しない情報を、位置関係や施設名などから推測して補完することは原則として行いません。

### 空欄は「なし」とは限らない

設備項目などが空欄の場合、

```text
設備が存在しない
```

ことを意味するとは限りません。

多くの場合は、

```text
元データから確認できない
```

ことを意味します。

たとえば車椅子対応、オストメイト設備、おむつ交換設備などについて、公開元に情報がなければ空欄のまま保持します。

### 意味が一致しない項目は無理に変換しない

自治体ごとに、

- 多目的トイレ
- 多機能トイレ
- だれでもトイレ
- 障がい者用トイレ
- 身障者対応トイレ

など、さまざまな表現があります。

これらを名称だけで同一設備と判断せず、元データの意味が標準項目と明確に対応する場合のみ変換します。

## `data/normalized/`

公開元のデータを、都道府県・自治体単位で正規化した結果です。

例:

```text
data/normalized/
├── 01-北海道/
├── 02-青森県/
├── ...
└── 47-沖縄県/
```

公衆トイレの場合は、原則として次のような構成になります。

```text
data/normalized/13-東京都/
└── 13101-千代田区/
    └── public-toilet/
        └── public-toilet.csv
```

元データそのものはこの公開リポジトリには含めていません。

## 出典情報

公開元、ライセンス、確認日などは、

```text
catalog/datasets.csv
```

で管理しています。

主な項目:

| 項目 | 内容 |
| --- | --- |
| `dataset_id` | データセット固有ID |
| `prefecture_code` | 都道府県コード |
| `prefecture_name` | 都道府県名 |
| `municipality_code` | 自治体コード |
| `municipality_name` | 自治体名 |
| `dataset_type` | データ種別 |
| `title` | 公開元データセット名 |
| `source_url` | 公開元ページ |
| `download_url` | データ取得先 |
| `format` | 元データ形式 |
| `standard` | 標準データとの関係 |
| `license` | ライセンス |
| `license_url` | ライセンス・利用条件確認先 |
| `attribution` | 出典表示 |
| `update_date` | 公開元データ更新日 |
| `last_checked` | Open Infra Japanでの最終確認日 |
| `publication_status` | 公開元の公開状態 |

## 正規化データと出典の対応

```text
catalog/normalized_sources.csv
```

で、正規化済みファイルと元データセットの対応を管理しています。

主な項目:

```text
normalized_path
dataset_id
role
```

1つの正規化済みデータが複数の公開データセットを統合して作られる場合にも対応できるよう、固定の `dataset_id` で出典を管理しています。

## 公衆トイレの標準化

公衆トイレについては、デジタル庁「自治体標準オープンデータセット」の公衆トイレ一覧を基本的なschemaとして扱っています。

標準形式ではない自治体データも対象とし、元データの意味を確認したうえで共通形式へ変換しています。

独自項目や標準項目と意味が完全には一致しない情報については、無理に変換せず、必要に応じて備考等へ保持します。

---

## データ品質

正規化時には、主に次の項目を確認しています。

- 必須項目
- 列構成
- 自治体コード
- 緯度・経度
- 重複
- 安定した施設ID
- 出典情報
- ライセンス情報
- 設備情報
- 正規化結果の再現性

データ品質を高めるため、人による確認が必要なケースも個別に検証しています。

---

## 座標について

公開元に正しい座標が存在する場合は、その値を使用します。

公開元に座標がない場合や、値が明らかに不完全な場合に、施設名や住所から自動的に位置を推定して補完することは原則として行いません。

そのため、一部の施設では緯度・経度が空欄になっている場合があります。

---

## 設備情報について

公衆トイレでは、可能な範囲で次のような設備情報を共通化しています。

- 車椅子対応
- 多目的トイレ
- オストメイト
- ベビーベッド
- ベビーチェア
- 大人用ベッド
- 授乳スペース
- おむつ交換設備

ただし、自治体によって公開項目や表現が異なります。

値が空欄の場合は、原則として

```text
設備なし
```

ではなく、

```text
元データから確認できない
```

として扱ってください。

## 元データについて

自治体・公的機関から取得した元ファイルは、公開リポジトリには原則として含めていません。

理由は主に次のとおりです。

- データ提供元ごとに再配布条件が異なる
- 元ファイルの更新履歴によるGitリポジトリ肥大化を避ける
- 公開元の最新データを直接確認できるようにする
- 原本とOpen Infra Japanによる加工データを明確に分離する

元データの公開元については、

```text
catalog/datasets.csv
```

を参照してください。

## ライセンス

Open Infra Japanが作成したプログラム・文書と、自治体・公的機関由来のデータでは、適用されるライセンスが異なる場合があります。

コードのライセンスについては、

```text
LICENSE
```

を参照してください。

データの利用条件については、

```text
LICENSE-DATA.md
catalog/datasets.csv
```

を確認してください。

各データの利用にあたっては、元データ提供者が定めるライセンス・利用条件が優先されます。

---

## 注意事項

このデータは、自治体・公的機関が公開した情報を整理・加工したものです。

最新性、完全性、正確性を保証するものではありません。

特に災害時・緊急時に施設を利用する場合は、このデータだけに依存せず、自治体や施設管理者などの最新の公式情報も確認してください。

施設の閉鎖、移転、利用時間の変更、設備変更などが、元データへ反映されるまで時間がかかる場合があります。
